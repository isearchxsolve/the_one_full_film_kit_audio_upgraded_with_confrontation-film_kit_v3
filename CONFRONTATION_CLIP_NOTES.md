# Confrontation Clip

This is a standalone notebook and pipeline for the office confrontation beat from THE ONE.

Files added:

- `kaggle_run_confrontation.ipynb` — the notebook to render only this clip.
- `config_confrontation.yaml` — points the pipeline to the standalone clip assets.
- `shots_confrontation.json` — the confrontation video prompt.
- `script/lines_confrontation.csv` — dramatic narration + faint chorus layer.
- `audio/prompts_confrontation.csv` — original-score and ambience direction.
- `src/filmforge_confrontation.py` — the render pipeline.

It uses the same upgraded audio work already applied to THE ONE: cinematic voice casting, original dramatic score generation, dialogue ducking, chorus mixing, and final mastering.
